# 📚 Estrutura de Dados em Java

Este repositório reúne exercícios e projetos desenvolvidos durante as aulas da disciplina de **Estrutura de Dados** na faculdade.

Os projetos acompanham a evolução do aprendizado ao longo do semestre, aplicando conceitos fundamentais de programação utilizando **Java**.

---

## 🎯 Objetivo

Praticar e consolidar conceitos importantes como:

- Lógica de programação
- Recursividade
- Organização de código
- Estruturação de projetos Java
- Separação e modularização de responsabilidades

---

## 📂 Organização do Repositório

Os projetos estão divididos por matérias:

grifo_lista/</br>
lista_simples/</br>
lista_encadeada/</br>
...


Cada aula pode possuir estruturas diferentes, conforme o conteúdo abordado.

Estrutura mais comum dos projetos:


src/ → Código-fonte</br>
dist/ → Arquivos compilados


---

## ▶️ Como executar um projeto

1. Acesse a pasta da aula desejada
2. Entre na pasta `src`
3. Compile os arquivos:

```bash
javac */*.java
```

Execute a classe principal do projeto correspondente.

💻 Tecnologias utilizadas
- Java
- Programação Orientada a Objetos
- Estruturas de Dados

📘 Projetos desenvolvidos para fins acadêmicos.
